pk3DS Mac Port prepara una versión para macOS del editor de ROMs de juegos Pokémon para Nintendo 3DS.

El proyecto está desarrollado en C# y toma como base las herramientas de pk3DS, conocidas por sus opciones de edición y randomización de entrenadores, encuentros, movimientos, evoluciones y más.

Todavía no hay una descarga pública. Las próximas actualizaciones indicarán cuándo habrá una versión apta para pruebas y cómo enviar reportes de compatibilidad.
